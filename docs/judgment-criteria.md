# 판단 기준

전체 세션 기록(2026-07-08 ~ 2026-08-03, 사용자 발화 1,414건)에서 **이미 나온 결과물을 고치라고 지시한 발화** 약 300건을 추출하고, 2회 이상 반복된 것만 남겨 정리한 문서.

자율 실행 시 에이전트가 사용자 확인 없이 판단해야 하는 지점의 기본값으로 사용함.

- 근거 수집 범위: `~/.claude/projects/**/*.jsonl` 전체 (29개 프로젝트, 706개 세션 파일)
- 각 표의 `반복`은 서로 다른 날짜·맥락에서 같은 취지의 지시가 나온 횟수
