# 사용 통계 — 산출물 예시

작업 대시보드 "사용 통계" 기능이 내야 할 결과물의 기준 예시. 2026-08-03 에 07/27~07/31 + 08/03 구간을 수동 분석한 실제 산출물임.

기능 구현 시 이 문서의 **표 구성과 판정 근거 수준**을 목표로 함. 화면 문구·수치는 이 예시를 그대로 쓰지 않고 조회 시점 데이터로 채움.

## 4. 책임 주체별 수정안

집계 결과를 사용자 지시 문제 / 에이전트 문제 / 자동화 장치 문제로 분리함. 분리하지 않으면 개선 대상이 흐려짐.

### 4.1 에이전트(Claude)

| 문제 | 수정 방향 |
| --- | --- |
| 현재 코드 상태 미확인 후 구현 착수 | 수정 요청은 구현 허가가 아님. "정합성 확인" 류 지시에는 진단 보고까지만 하고 멈춤 |
| Read 없이 Edit 42회 | 파일 편집 전 Read 예외 없이 선행 |
| 없는 경로·미설치 명령 실행 117회 | 경로·바이너리 존재 확인을 같은 턴에 묶어 실행 |
| 사용자 편집 덮어쓰기 | 규칙은 이미 존재하므로 위반 사례. 문서 수정 전 재조회 무조건 선행 |
| 확정된 설계 재질문 | 세션 내 합의 사항은 재확인하지 않음 |

## 결론 형식

산출물 마지막에는 우선순위가 붙은 한두 문장이 있어야 함. 표만 나열하고 끝내지 않음.

예시 — 효과가 가장 큰 단일 조치는 GateGuard 편집 게이트 축소(툴 에러의 71% 제거)이고, 그다음이 AGENTS.md 에 "구현 착수 전 현재 상태 보고" 조항 추가임
